MEDIA SERVICE API LIST
Base URL: /api/media

Ghi chú chung
- `x-user-id`: Hệ thống tự set từ gateway/auth service, frontend/client không nên tự điền tay.
- `x-internal-secret`: Hệ thống nội bộ tự set khi gọi qua gateway/service nội bộ.
- API có `SkipInternalGatewayGuard` là API public, không cần `x-internal-secret`.
- Với endpoint `POST`, nếu không override thì NestJS mặc định trả HTTP 201.
- Các endpoint bên dưới hiện trả DTO trực tiếp. Format `ApiError` áp dụng cho lỗi.

2. CHANNEL APIs

2.1) POST /api/media/channels
- Mục đích: tạo channel mới.
- Header:
  - `x-user-id`: Hệ thống tự set

  - `bio` (string, bắt buộc, max 1000): Người dùng nhập
- Hệ thống tự set thêm khi xử lý:
  - `userId`: lấy từ header `x-user-id`
- Response 201:

  - `userId` (string)

  - `bio` (string)
  - `isEligibleForMembership` (boolean)
  - `avatarUrl` (string)
  - `bannerUrl` (string)

  - `createdAt` (string ISO)
  - `updatedAt` (string ISO)

2.2) PATCH /api/media/channels/:id

  - `createdAt` (string ISO)

- Header:

- Body:
  - `channelId` (string, bắt buộc): Người dùng/client truyền lên
  - `title` (string, bắt buộc, max 200): Người dùng nhập
  - `description` (string, optional, default `""`): Người dùng nhập
  - `category` (string, optional, default `general`): Người dùng nhập
  - `visibility` (`public` | `private`, optional, default `public`): Người dùng nhập
  - `price` (number, optional, default 0): Người dùng nhập
  - `requiredTierLevel` (number | null, optional, min 1): Người dùng nhập
- Hệ thống tự set thêm khi xử lý:

4.7) GET /api/media/videos/:id/metadata
- Muc dich: lay metadata public cua video.
- Public API: khong can `x-internal-secret`.
- Path param:
  - `id` (string): Video id
- Ghi chu:
  - Chi tra video co `status = public` va `visibility = public`.
  - Neu video khong ton tai hoac khong public thi tra `NOT_FOUND` / HTTP 404.
  - Cache key: `video:{id}:metadata`, TTL 600s.
- Response 200:
  - `id` (string)
  - `title` (string)
  - `description` (string)
  - `thumbnailUrl` (string | null)
  - `status` (string)
  - `visibility` (string)
  - `publishedAt` (string ISO | null)
  - `updatedAt` (string ISO)

4.8) PATCH /api/media/videos/:id/metadata
- Muc dich: creator cap nhat metadata cua video.
- Header:
  - `x-user-id`: Gateway verify JWT roi tu set
  - `x-internal-secret`: Gateway/service noi bo tu set, client khong tu gui
- Path param:
  - `id` (string): Video id
- Body:
  - `title` (string, optional, max 200): Nguoi dung nhap
  - `description` (string, optional): Nguoi dung nhap
  - `thumbnailUrl` (string | null, optional, max 500): Nguoi dung nhap hoac client set tu
    upload result
- Ghi chu:
  - Chi owner duoc sua; non-owner tra `FORBIDDEN` / HTTP 403.
  - Sau khi save chi xoa cache key `video:{id}:metadata`.
  - Khong xoa discovery list cache; latest/by-category tu refresh theo TTL 600s.
- Response 200:
  - `id` (string)
  - `title` (string)
  - `description` (string)
  - `thumbnailUrl` (string | null)
  - `status` (string)
  - `visibility` (string)
  - `publishedAt` (string ISO | null)
  - `updatedAt` (string ISO)

5. STREAMING APIs
==================================================

5.1) GET /api/media/stream/:videoId/master.m3u8?token=...
- Mục đích: lấy file playlist HLS master.
- Public theo guard nội bộ:
  - Không có `x-internal-secret`
  - Nhưng bắt buộc phải có playback `token`
- Path param:
  - `videoId` (string): Hệ thống/client phát video truyền lên
- Query:
  - `token` (string, bắt buộc): Hệ thống tự set từ API `GET /videos/:id/play`
- Response 200:
  - Content-Type: `application/vnd.apple.mpegurl`
  - Body: nội dung text của file m3u8

5.2) GET /api/media/stream/:videoId/segments/:segmentName?token=...
- Mục đích: lấy segment video HLS.
- Public theo guard nội bộ:
  - Không có `x-internal-secret`
  - Nhưng bắt buộc phải có playback `token`
- Path param:
  - `videoId` (string): Hệ thống/client phát video truyền lên
  - `segmentName` (string): Hệ thống player tự set theo playlist m3u8
- Query:
  - `token` (string, bắt buộc): Hệ thống tự set từ API `GET /videos/:id/play`
- Response 200:
  - Body: binary stream của segment

7. ERROR RESPONSE CHUNG
==================================================

Khi lỗi, service dùng format:
{
  "success": false,
  "code": 400,
  "mess": "Error message",
  "data": null,
  "errors": ["Error detail"],
  "requestId": "1744712345-abc1234",
  "timestamp": "2026-04-15T10:19:05.123Z",
  "path": "/api/media/..."
}

Mapping phổ biến:
- `NOT_FOUND` -> 404
- `BAD_REQUEST` -> 400
- `UNAUTHORIZED` -> 401
- `FORBIDDEN` -> 403
- `CONFLICT` -> 409
- `INTERNAL_SERVER_ERROR` -> 500
